# 🚀 Shaqran Hussain - Portfolio Website

A modern, responsive portfolio website showcasing my skills as a Python Developer, QA Prompt Engineer, and Data Analyst.

![Portfolio Preview](assets/images/og-image.png)

## ✨ Features

- **Modern Design** - Dark/Light mode with glassmorphism effects
- **Responsive** - Works on all devices (desktop, tablet, mobile)
- **Animated** - Smooth scroll animations, 3D tilt effects, typing animation
- **SEO Optimized** - Meta tags, JSON-LD structured data, sitemap
- **Contact Form** - Integrated with Web3Forms for email notifications
- **Premium Loading** - Animated loader with percentage counter

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Grid, Flexbox, animations
- **JavaScript** - Vanilla JS with modern ES6+ features
- **Libraries** - VanillaTilt.js for 3D effects

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Shaqran92/portfolio.git
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   # Or use a local server:
   npx serve .
   ```

3. **Deploy** 
   - GitHub Pages: Push to `main` branch and enable Pages
   - Netlify: Drag & drop the folder
   - Vercel: Connect your GitHub repo
